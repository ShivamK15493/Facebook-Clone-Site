
<h1>📘 Facebook Login Page </h1>
A Facebook Login Page UI Clone built using HTML and CSS. This project focuses on recreating the visual layout of Facebook's login interface for learning and practice purposes.

<h2>🚀 Features</h2>
<ul>
  <li>📱 Responsive layout using Flexbox</li>
  <li>🎨 Clean and minimal UI design</li>
  <li>🔐 Login form with email & password fields</li>
  <li>🔗 "Forgotten Password?" and "Create New Account" options</li>
  <li>💡 Beginner-friendly project for HTML & CSS practice</li>
</ul>

<h2>📸 Preview</h2>
<ul>
  <li>Facebook logo section</li>
  <li>Login form UI</li>
  <li>Buttons and links styling</li>
</ul>

<h2>📌 Learning Outcomes</h2>
<ul>
  <li>Understanding Flexbox layout</li>
  <li>Styling forms and buttons</li>
  <li>Working with spacing, alignment, and fonts</li>
  <li>Building real-world UI clones</li>
</ul>
